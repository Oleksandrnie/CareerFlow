# CareerFlow 0.1.0 — draft release notes

**Status:** draft only. This release has not been published. Target version follows the package metadata; date and Git tag are intentionally unset until the owner approves publication.

CareerFlow 0.1.0 is the first prepared release of a local-first workspace for organizing a job search.

## Included

- Vacancy tracking with status history, interview events, notes, attachments and Markdown reports.
- Master Resume library and immutable vacancy-specific resume versions with lineage.
- Vacancy import from text, supported documents and public static HTML, with review before saving.
- Local heuristic ATS comparisons with resume and vacancy-description provenance.
- Optional, explicitly invoked Codex CLI workflows that return read-only text until the user saves a resume version.
- English and Russian UI, responsive layouts, and light/dark themes.
- Local SQLite storage, migration support, and loopback-only default server binding.

## Requirements and limitations

- Python 3.11 or newer.
- Single-user local application; no authentication, multi-user mode, hosted deployment or cloud sync.
- Codex CLI actions may transmit the selected context through the user's configured Codex account.
- PDF text extraction requires an embedded text layer. Vacancy URL import does not run JavaScript or authenticate to a site.
